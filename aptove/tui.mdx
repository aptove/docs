## Overview

Running `aptove` without arguments opens the TUI — a full-screen terminal application built with [Ratatui](https://ratatui.rs). It handles both initial setup and day-to-day operation.

## Screens

### Setup wizard

On first run (or when required configuration is missing), the wizard runs before Aptove Router starts:

| Step | Triggered when |
|------|---------------|
| Agent select | `agent_command` is not set |
| Transport pick | No transports are enabled, or 2+ are enabled |
| Push notifications | `push_selection` is not set |
| QR code | Always — final step of first-run setup |

The wizard writes your choices to `common.toml` and starts Aptove Router automatically. The QR pairing code is shown as the last wizard step — scan it with the Aptove app to pair immediately.

For a full walkthrough of each wizard step, what happens if the agent command is wrong, and how the mobile app shows the result, see [Setup Wizard](/aptove/setup-wizard).

### Running screen

Once Aptove Router is running, the TUI shows a three-panel layout:

- **Status bar** (top) — Aptove Router health, connected clients, active transport
- **Log panel** (center) — scrollable log stream filtered by `log_level`
- **Input bar** (bottom) — accepts slash commands

## Slash commands

Type these in the input bar while Aptove Router is running:

| Command | Description |
|---------|-------------|
| `/qr` | Show QR pairing code for the mobile app |
| `/agent` | Change the AI agent |
| `/transport` | Change the transport |
| `/push` | Configure push notifications |
| `/keep-alive` | Toggle to prevent the computer to sleep |
| `/log-level` | Change log verbosity (default: WARN) |
| `/rotate-token` | Rotate auth token (disconnects all paired devices) |
| `/quit` | Exit Aptove |

## Keyboard shortcuts

| Key | Action |
|-----|--------|
| `Esc` | Close popup / cancel wizard step |
| `Enter` | Confirm / submit |
| `↑` / `↓` | Navigate lists |
| `q` | Quit (when no input is focused) |

## Popups

- **QR code** — displayed after `/qr`. Scan with the Aptove app to pair. (During first-run setup, the QR is shown as the last wizard step rather than a popup.)
- **Help** — lists all TUI commands.

<Tip>
To change the agent command without restarting, type `/agent` in the input bar.
</Tip>
