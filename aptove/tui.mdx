## Overview

Running `aptove` without arguments opens the TUI — a full-screen terminal application built with [Ratatui](https://ratatui.rs). It handles both initial setup and day-to-day operation.

## Screens

### Setup wizard

On first run (or when required configuration is missing), the wizard runs before Aptove CLI starts:

| Step | Triggered when |
|------|---------------|
| Agent select | `agent_command` is not set |
| Transport pick | No transports are enabled, or 2+ are enabled |

The wizard writes your choices to `common.toml` and then starts Aptove CLI automatically. After the wizard, the QR pairing code is shown immediately.

### Running screen

Once Aptove CLI is running, the TUI shows a three-panel layout:

- **Status bar** (top) — Aptove CLI health, connected clients, active transport
- **Log panel** (center) — scrollable log stream filtered by `log_level`
- **Input bar** (bottom) — accepts slash commands

## Slash commands

Type these in the input bar while Aptove CLI is running:

| Command | Description |
|---------|-------------|
| `/qr` | Show QR pairing code for the mobile app |
| `/agent` | Change the AI agent |
| `/transport` | Change the transport |
| `/keep-alive` | Toggle to prevent the computer to sleep |
| `/log-level` | Change log verbosity (default: WARN) |
| `/clear-logs` | Clear the log view |
| `/quit` | Exit Aptove CLI |

## Keyboard shortcuts

| Key | Action |
|-----|--------|
| `Esc` | Close popup / cancel wizard step |
| `Enter` | Confirm / submit |
| `↑` / `↓` | Navigate lists |
| `q` | Quit (when no input is focused) |

## Popups

- **QR code** — displayed after `/qr` or automatically after the wizard completes. Scan with the Aptove app to pair.
- **Help** — lists all TUI commands.

<Tip>
To change the agent command without restarting, type `/agent` in the input bar.
</Tip>
