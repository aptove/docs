---
title: "Rotating the Auth Token"
description: "How to rotate the auth token to revoke access from all paired devices, and what to do if a phone is lost or stolen."
---

Aptove Router issues one shared auth token to every device that pairs with it. Rotating the token replaces it with a new random value and immediately invalidates every device that holds the old one. All other settings — agent ID, agent command, push credentials — are preserved.

---

## Using `/rotate-token`

1. In the TUI, type `/rotate-token` and press **Enter**.
2. A confirmation prompt appears. Press **Enter** to confirm, or **Esc** to cancel.
3. Aptove Router generates a new token, saves it to `common.toml`, and restarts the bridge.
4. All currently connected devices are disconnected. Any reconnect attempt using the old token receives **HTTP 401 Unauthorized**.
5. The QR pairing screen opens automatically. Re-pair each device by scanning the new QR code.

---

## Command-line alternative

If Aptove Router is not running, open `common.toml` in a text editor and replace the `auth_token` value with a new random string, then relaunch Aptove. The startup log prints the config directory path:

```
[INFO] Config directory: /Users/you/.aptove/projects/Users-you-myproject/
```

Edit the file:

```toml
# common.toml
auth_token = "<paste-a-new-random-value>"
```

You can generate a suitable value with:

```bash
openssl rand -base64 32 | tr '+/' '-_' | tr -d '='
```

---

## Full reset (nuclear option)

If you also want to reset the agent ID and all other credentials, delete `common.toml` and relaunch:

```bash
# macOS / Linux — replace the path with your actual project path
rm ~/.aptove/projects/$(pwd | sed 's|^/||')/common.toml
aptove
```

The setup wizard runs on the next launch and generates a fresh agent ID and token. Every paired device must re-pair.

---

## Lost or stolen phone

If a device is lost or stolen:

1. Run `/rotate-token` in the TUI.
2. The old token is immediately invalid — any reconnect attempt from the stolen device receives **HTTP 401**.
3. Re-pair your remaining devices by scanning the new QR code (`/qr`).
4. If push notifications are configured, the stolen device's push token is still registered with the relay. To remove it, sign in at [dash.aptove.com](https://dash.aptove.com), delete the push client, then reconfigure push on your other devices via `/push`.
