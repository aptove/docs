## What to enter

When Aptove Router asks for an agent command, enter the shell command that starts your AI agent. The command must launch a process that speaks the [Agent Client Protocol](https://agentclientprotocol.com) over **stdio** (stdin / stdout).

Aptove Router will spawn this command as a subprocess and relay messages between it and the Aptove mobile app.

---

## Available agents

### GitHub Copilot

Requires the [GitHub Copilot CLI extension](https://docs.github.com/en/copilot/using-github-copilot/using-github-copilot-in-the-command-line).

```
copilot --acp
```

#### Yolo mode

Yolo mode skips confirmation prompts, letting Copilot execute tool calls automatically without asking each time.

<Warning>
`--yolo` removes all human confirmation steps. The agent can read and write files, run shell commands, and make API calls without prompting. Only use this mode on a machine where you are comfortable with autonomous execution — ideally inside a sandboxed environment such as a Docker container or a dedicated virtual machine, not on your primary workstation.
</Warning>

```
copilot --acp --yolo
```

### Google Gemini

Requires the [Gemini CLI](https://github.com/google-gemini/gemini-cli).

```
gemini --experimental-acp
```

### Goose AI

Requires [Goose](https://github.com/block/goose).

```
goose acp
```

### OpenAI Codex (via codex-acp)

Requires Node.js. Runs the ACP wrapper for OpenAI Codex CLI.

```
npx @agentclientprotocol/codex-acp
```

Or install globally first:

```bash
npm install -g @agentclientprotocol/codex-acp
codex-acp
```

### Claude (via claude-agent-acp)

Requires Node.js. Runs the ACP wrapper for Claude.

```
npx @agentclientprotocol/claude-agent-acp
```

Or install globally first:

```bash
npm install -g @agentclientprotocol/claude-agent-acp
claude-agent-acp
```

#### Yolo mode

Yolo mode skips all permission prompts, letting Claude run shell commands and edit files without asking for confirmation.

<Warning>
`--dangerously-skip-permissions` removes all human confirmation steps. Claude can execute arbitrary shell commands, modify files, and perform tool calls without prompting. Only use this mode on a machine you control and are comfortable with autonomous execution — ideally inside a sandboxed environment such as a Docker container or a dedicated virtual machine, not on your primary workstation with broad filesystem access.
</Warning>

```
npx @agentclientprotocol/claude-agent-acp --dangerously-skip-permissions
```

### Custom / other agents

Any process that implements the ACP stdio protocol can be used. Enter the full shell command including arguments:

```
my-agent --acp --model gpt-4
```

## Process lifecycle

Aptove Router starts the agent command as a managed subprocess and terminates it when the session ends or Aptove Router exits. If Aptove Router crashes or is killed hard (`kill -9`), the agent subprocess may be left running. To clean up orphaned processes:

```bash
# Find and kill a stale claude-agent-acp process
pkill -f "claude-agent-acp"
# Or for Copilot
pkill -f "copilot --acp"
```

Running agents in a container avoids this entirely — the container's process group is cleaned up automatically when the container stops.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `Failed to start 'copilot --acp'` | Agent is not installed or not on `$PATH` |
| Agent starts but Aptove Router shows no clients | Agent is not in ACP mode — add the required flag (e.g. `--acp`) |
| Agent exits immediately | Run the command manually in a terminal to see the error output |
