---

## Shell installer (recommended)

The quickest way to install on macOS and Linux. Requires no Node.js or Rust toolchain.

```bash
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/aptove/bridge/releases/latest/download/bridge-installer.sh | sh
```

On Windows (PowerShell):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://github.com/aptove/bridge/releases/latest/download/bridge-installer.ps1 | iex"
```

## npm

An alternative if you already have [Node.js](https://nodejs.org) installed.

Run directly without installing:

```bash
npx @aptove/bridge
```

Or install globally so `bridge` is available anywhere:

```bash
npm install -g @aptove/bridge
bridge
```

## Build from source

If you have a [Rust toolchain](https://rustup.rs) installed:

```bash
git clone https://github.com/aptove/bridge
cd bridge
cargo build --release
./target/release/bridge
```

Use this if you want to build a specific commit or develop against the bridge codebase.

## Comparison

| Method | Requires | Speed | Best for |
|--------|----------|-------|----------|
| Shell / PowerShell installer | Nothing extra | Fast | Most users |
| npm / npx | Node.js | Fast (cached after first run) | Node.js users |
| Build from source | Rust toolchain + git | ~2–5 min compile | Contributors / custom builds |
