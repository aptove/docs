## What is the bridge?

The bridge is a small, self-contained binary that runs on any machine where your AI agent lives — your laptop, a home server, or a cloud VM. It does three things:

- **Launches your agent** as a child process and pipes ACP messages over stdin/stdout.
- **Exposes a WebSocket server** so the Aptove mobile app can connect and exchange messages.
- **Manages transports** so you can reach the bridge whether you're on the same Wi-Fi network or on the other side of the world.

## Architecture

```
┌─────────────────────────────────────────────────┐
│                  aptove-bridge                   │
│                                                  │
│   WebSocket server ◄──── Transport layer         │
│          │                (local / Tailscale)    │
│          ▼                                       │
│     Agent process (stdio ACP)                    │
└─────────────────────────────────────────────────┘
```

## Installation

### Pre-built binary

Download the latest release for your platform from the [GitHub releases page](https://github.com/aptove/bridge/releases).

### Build from source

```bash
git clone https://github.com/aptove/bridge
cd bridge
cargo build --release
# binary is at target/release/bridge
```

## First run

Running `bridge` with no arguments starts the interactive TUI. On first launch, the setup wizard appears and walks you through:

1. Choosing an agent command (e.g. `copilot --acp`)
2. Picking a transport (local or Tailscale)
3. Configuring any transport-specific credentials

After setup, the bridge starts and immediately shows a QR code for pairing your phone.

## Supported agents

The wizard offers a list of known agents. Select **Custom** to use any ACP-compatible agent not on the list.

| # | Agent | Command |
|---|-------|---------|
| 1 | GitHub Copilot | `copilot --acp` |
| 2 | Gemini | `gemini --experimental-acp` |
| 3 | Goose | `goose acp` |
| 4 | **Custom** | *(any command)* |

### Claude (via `claude-agent-acp`)

To use Claude, select **Custom** and enter:

```
npx @agentclientprotocol/claude-agent-acp
```

This runs the [`@agentclientprotocol/claude-agent-acp`](https://www.npmjs.com/package/@agentclientprotocol/claude-agent-acp) package, which wraps Claude in an ACP-compatible stdio interface. Node.js must be installed on your machine.

You can also set this directly in `common.toml`:

```toml
agent_command = "npx @agentclientprotocol/claude-agent-acp"
```

## Configuration file

All settings are stored in `common.toml` inside the `.aptove-bridge/` directory created wherever you ran the bridge. See [Configuration](/bridge/configuration) for the full reference.
