## Overview

Running `bridge` without arguments opens the TUI — a full-screen terminal application built with [Ratatui](https://ratatui.rs). It handles both initial setup and day-to-day operation.

## Screens

### Setup wizard

On first run (or when required configuration is missing), the wizard runs before the bridge starts:

| Step | Triggered when |
|------|---------------|
| Agent select | `agent_command` is not set |
| Transport pick | No transports are enabled, or 2+ are enabled |
| Cloudflare setup | Cloudflare transport is enabled but `tunnel_id` is missing |
| Push setup | `[push_relay]` section is absent |

The wizard writes your choices to `common.toml` and then starts the bridge automatically. After the wizard, the QR pairing code is shown immediately.

### Running screen

Once the bridge is running, the TUI shows a three-panel layout:

- **Status bar** (top) — bridge health, connected clients, active transport
- **Log panel** (center) — scrollable log stream filtered by `log_level`
- **Input bar** (bottom) — accepts slash commands

## Slash commands

Type these in the input bar while the bridge is running:

| Command | Description |
|---------|-------------|
| `/qr` | Show QR pairing code |
| `/agent` | Change the AI agent command |
| `/push` | Configure push notifications |
| `/test-push` | Send a test push notification to all registered devices |
| `/reconnect` | Restart the transport |
| `/keep-alive` | Toggle prevent-sleep (enabled by default) |
| `/log-level` | Change log verbosity (default: WARN) |
| `/clear-logs` | Clear the log view |
| `/copy-logs` | Copy all logs to clipboard |
| `/help` | List all available commands |
| `/quit` | Exit the bridge |

## Keyboard shortcuts

| Key | Action |
|-----|--------|
| `Esc` | Close popup / cancel wizard step |
| `Enter` | Confirm / submit |
| `↑` / `↓` | Navigate lists |
| `q` | Quit (when no input is focused) |

## Popups

- **QR code** — displayed after `/qr` or automatically after the wizard completes. Scan with the Aptove app to pair.
- **Help** — lists all TUI commands.

<Tip>
To change the agent command without restarting, type `/agent` in the input bar. To reconfigure Cloudflare credentials, run `bridge setup` from a new terminal — it re-runs the Cloudflare setup wizard.
</Tip>
