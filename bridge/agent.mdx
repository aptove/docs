## What to enter

When the bridge asks for an agent command, enter the shell command that starts your AI agent. The command must launch a process that speaks the [Agent Client Protocol](https://agentclientprotocol.com) over **stdio** (stdin / stdout).

The bridge will spawn this command as a subprocess and relay messages between it and the Aptove mobile app.

---

## Available agents

### GitHub Copilot

Requires the [GitHub Copilot CLI extension](https://docs.github.com/en/copilot/using-github-copilot/using-github-copilot-in-the-command-line).

```
copilot --acp
```

#### Yolo mode

Yolo mode skips confirmation prompts, letting Copilot execute tool calls automatically without asking each time.

```
copilot --acp --yolo
```

### Google Gemini

Requires the [Gemini CLI](https://github.com/google-gemini/gemini-cli).

```
gemini --experimental-acp
```

### Goose AI

Requires [Goose](https://github.com/block/goose).

```
goose acp
```

### OpenAI Codex (via codex-acp)

Requires Node.js. Runs the ACP wrapper for OpenAI Codex CLI.

```
npx @agentclientprotocol/codex-acp
```

Or install globally first:

```bash
npm install -g @agentclientprotocol/codex-acp
codex-acp
```

### Claude (via claude-agent-acp)

Requires Node.js. Runs the ACP wrapper for Claude.

```
npx @agentclientprotocol/claude-agent-acp
```

Or install globally first:

```bash
npm install -g @agentclientprotocol/claude-agent-acp
claude-agent-acp
```

#### Yolo mode

Yolo mode skips all permission prompts, letting Claude run shell commands and edit files without asking for confirmation. Use with caution.

```
npx @agentclientprotocol/claude-agent-acp --dangerously-skip-permissions
```

### Custom / other agents

Any process that implements the ACP stdio protocol can be used. Enter the full shell command including arguments:

```
my-agent --acp --model gpt-4
```

## How the connection test works

After you enter a command, the bridge performs a full ACP handshake and sends a test prompt. The steps are:

1. **`initialize`** — negotiates the protocol version
2. **`session/new`** — creates a session and retrieves a `sessionId`
3. **`session/prompt`** — sends _"Hello, what is your name?"_ and waits for the agent's reply via `session/update` notifications

**Sent (session/prompt):**
```json
{
  "jsonrpc": "2.0",
  "id": "aptove-prompt",
  "method": "session/prompt",
  "params": {
    "sessionId": "<session-id from step 2>",
    "prompt": [{"type": "text", "text": "Hello, what is your name?"}]
  }
}
```

**Expected received (success):**

The bridge displays the agent's text reply, for example:
```
Hi! I'm Claude, an AI assistant made by Anthropic...
```

If the agent responds correctly, press **Enter** to continue to transport setup. If you see an error, check that the agent is installed and the command is correct.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `Failed to start 'copilot --acp'` | Agent is not installed or not on `$PATH` |
| `Timeout: no response within 10 seconds` | Agent started but does not speak ACP — check the command and version |
| `Agent closed stdout without responding` | Agent exited immediately — run the command manually in a terminal to see the error output |
| Response is not valid JSON | Agent is not in ACP mode — add the required flag (e.g. `--acp`) |
