## Shell installer (recommended)

The quickest way to install on macOS and Linux. Requires no Node.js or Rust toolchain.

```bash
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/aptove/bridge/releases/latest/download/aptove-bridge-installer.sh | sh
```

On Windows (PowerShell):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://github.com/aptove/bridge/releases/latest/download/aptove-bridge-installer.ps1 | iex"
```

## Build from source

If you have a [Rust toolchain](https://rustup.rs) installed:

```bash
git clone https://github.com/aptove/bridge
cd bridge
cargo build --release
./target/release/bridge
```

Use this if you want to build a specific commit or develop against the bridge codebase.

## Comparison

| Method | Requires | Best for |
|--------|----------|----------|
| Shell / PowerShell installer | Nothing extra | Most users |
| Build from source | Rust toolchain + git | Contributors / custom builds |
