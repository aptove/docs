## Chat

The chat view is the main interface for talking to an agent. Messages are sent over the WebSocket connection to Aptove Router, which pipes them to the agent process and streams the response back.

- **Streaming responses** — agent output appears word-by-word as it arrives
- **Markdown rendering** — responses are rendered with syntax highlighting for code blocks
- **Message history** — conversation history is stored locally on the device
- **Session continuity** — Aptove Router preserves the agent session between connections; you can close the app and resume later

## Voice input

Tap the microphone button in the chat input to dictate a message. The app uses the device's built-in speech recognition — no internet service or subscription required.

- Works offline on supported devices (iOS 16+ on-device recognition)
- Tap again or tap **Send** to confirm the transcription before sending

## Slash commands

Type `/` in the chat input to open the command picker. Commands are provided by the agent (via `available_commands_update`) or defined manually in Aptove Router's `common.toml`.

| Command type | Behavior |
|---|---|
| Simple command | Sends `/command` immediately |
| Command with input | Opens an additional text field; sends `/command <your text>` |

## Agent list

The home screen shows all paired agents with their connection status:

| Status | Meaning |
|--------|---------|
| Connected | WebSocket open, agent ready |
| Connecting | Reconnect attempt in progress |
| Disconnected | Could not reach Aptove Router |

Tap an agent to open the chat. Long-press for options: **Edit**, **Reconnect**, **Remove**.

## Starred messages

Star any message to save it for quick reference later — both your own messages and agent responses can be starred.

**Starring a message:**

Long-press a message bubble to open the context menu, then tap **Star**. A yellow star icon appears beneath the bubble to confirm it is starred. Tap **Unstar** from the same context menu to remove the star.

**Viewing starred messages:**

Tap the **Starred** tab (★) in the bottom navigation bar to see all starred messages across every agent, sorted by most recent.

- Use the search bar to filter by message content or agent name
- Tap any row to jump directly to that message in its conversation
- Swipe left on a row and tap **Unstar** to remove it

Starred messages are stored on-device and persist across app restarts.

## Settings

Access settings from the gear icon on the home screen:

- **Appearance** — light / dark / system theme
- **Agent configuration** — edit the name and icon for any paired agent
- **Verbose Messages** — when enabled (default), the chat shows the agent's internal reasoning steps and tool output alongside normal responses. Turn it off for a cleaner view that shows only the final responses and permission prompts.
