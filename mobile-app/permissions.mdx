The Aptove app requests the following iOS permissions. Each one is only used for the purpose described — the app does not access sensors or data in the background beyond what is listed here.

## Permissions reference

| Permission | When requested | Why it's needed |
|---|---|---|
| **Camera** | First QR scan | Scan the pairing QR code displayed by Aptove Router to establish a connection. |
| **Microphone** | First voice input | Record audio for speech-to-text during voice message dictation. |
| **Speech Recognition** | First voice input | Convert recorded audio to text using on-device speech recognition. |
| **Photo Library** | First image attachment | Access photos when you choose to attach an image to a chat message or set an agent avatar. |
| **Push Notifications** | First app launch | Deliver notifications when the agent sends a message while the app is in the background. |
| **File Access** | On file attach (no permission required) | Pick documents from Files, iCloud Drive, and third-party providers to send as attachments. |

## Notes

### Camera

Used exclusively for QR code scanning during the initial pairing flow. The camera is not accessed at any other time.

### Microphone and Speech Recognition

Both permissions are requested together the first time you tap the microphone button. Speech recognition runs on-device on iOS 16 and later — audio is not sent to any external server.

### Photo Library

The app uses the system photo picker, which lets you select images without granting broad library access. On iOS 14 and later you can grant access to specific photos only rather than your entire library.

### File Access

File attachment uses the iOS system document picker (`UIDocumentPickerViewController`), which runs in a separate process and does not require any permission grant from the user. You choose files interactively from Files, iCloud Drive, or any connected cloud storage provider.

Supported file types: PDF, plain text, CSV, JSON, RTF. Files must be no larger than 10 MB. If a selected file is stored in iCloud and has not yet been downloaded to the device, the app will show an error — download the file first and try again.

### Push Notifications

Notifications are delivered through APNs (Apple Push Notification service). They are only sent when Aptove Router has a push relay configured and you have completed the pairing flow. The app does not use notifications for marketing or analytics.
